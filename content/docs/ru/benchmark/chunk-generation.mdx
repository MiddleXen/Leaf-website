### Схема тестирования

Тестирование проводилось с использованием плагина Chunky для предварительной генерации чанков радиусом 2048 блоков по кругу. Оба сервера работали на идентичном оборудовании и с одинаковыми параметрами JVM для чистоты эксперимента.
