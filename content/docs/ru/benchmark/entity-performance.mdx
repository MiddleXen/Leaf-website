## Конфигурация тестов

### Базовая конфигурация по умолчанию

Оба сервера тестировались со стандартными настройками в bukkit.yml, spigot.yml и других файлах. Этот базовый тест отражает производительность в стандартных условиях.

### Конфигурация с повышенными лимитами мобов (Mob Caps)

Изменённые настройки в bukkit.yml:

- monsters: 70 → 700
- animals: 10 → 100

Все остальные конфигурации оставлены по умолчанию. Данный сценарий моделирует скопление большого количества сущностей, характерное для нагруженных серверов.

### Конфигурация Leaf + Async

Включены базовые асинхронные модули в leaf-global.yml:

```yaml
async:
  async-entity-tracker:
    enabled: true
  async-pathfinding:
    enabled: true
```
