title: Флаги JVM для Leaf
---

## -DLeaf.library-download-repo

- по умолчанию: не задано

Скорость загрузки из стандартного репозитория Maven Central может быть крайне низкой в некоторых регионах.

Этот флаг JVM позволяет указать зеркало репозитория для загрузчиков библиотек SpigotLibraryLoader или PaperLibraryLoader.

Например, флаг ниже переключает загрузку на зеркало Aliyun:

```bash
-DLeaf.library-download-repo=https://maven.aliyun.com/repository/public
```

## -DLeaf.enableFMA

- по умолчанию: `false`

Включает использование инструкций [Fused-Multiply-Add (FMA)](https://en.wikipedia.org/wiki/Multiply%E2%80%93accumulate_operation) для ускорения математических вычислений.

Требует процессора с поддержкой набора инструкций FMA, в противном случае производительность может упасть.

Проверить поддержку FMA вашим процессором можно с помощью утилит вроде [CPU-Z](https://www.cpuid.com/softwares/cpu-z.html) или `lscpu` на Linux.

## -DLeaf.disable-vanilla-profiler

- по умолчанию: `false`

Отключает встроенный ванильный профайлер Minecraft для небольшого снижения накладных расходов.

Рекомендуется включать этот флаг на продакшне, так как ванильный профайлер потребляет ресурсы, а для профилирования лучше использовать [Spark](https://spark.lucko.me/). Исключение — если вам необходимо профилировать функции датапаков.

Документация по Spark:

- [Использование команды `/spark`](https://spark.lucko.me/docs/Command-Usage)
- [Поиск просадок производительности (лаг-спайков)](https://spark.lucko.me/docs/guides/Finding-lag-spikes).

## -DLeaf.disable-vanilla-debug-feature

- по умолчанию: `false`

Полностью отключает [отладочные функции (Debug property)](https://minecraft.wiki/w/Debug_property) Minecraft.

Рекомендуется включать этот флаг, поскольку отладка расходует процессорное время, особенно при высоком онлайне. Снимайте этот флаг только тогда, когда вам действительно требуется отладочный функционал ваниллы.

## -DLeaf.enable-io-uring

- по умолчанию: `false`

Включает использование модели ввода-вывода `io_uring` для сетевой передачи данных на Linux. Требует включённого параметра `use-native-transport` и значения `network-compression-threshold: -1` в файле `server.properties`.

Если в текущей среде `io_uring` недоступен, сервер автоматически откатится на доступную модель (epoll/nio).

## -DLeaf.linear-v2-read-only

- по умолчанию: `false`

Включает режим «только чтение» для формата регионов Linear v2. В этом режиме любые изменения мира (включая чанки, точки интереса (POI), сущности и данные игроков) **НЕ будут сохраняться**.

Этот режим предназначен исключительно для инспекции, тестирования, миграции или аварийного восстановления.

Поскольку формат Linear v2 содержит ряд конструктивных недостатков и опасен для продакшна, мы рекомендуем использовать Buffered Linear при необходимости работы с форматом Linear.

## -DLeaf.enable-base64coder-warning

- по умолчанию: `false`

Включает вывод предупреждения в консоль, когда плагин использует устаревшие методы `Base64Coder` библиотеки SnakeYAML. Флаг удобен для отладки и выявления устаревших плагинов.

Подробнее см. в обсуждении [Leaf#571](https://github.com/Winds-Studio/Leaf/issues/571#issuecomment-3695175765).

## -Dgale.log.warning.root

- по умолчанию: `true`

Определяет, выводить ли предупреждение при запуске сервера от пользователя root или в привилегированном режиме.

## -Dgale.log.warning.offline.mode

- по умолчанию: `true`

Определяет, выводить ли предупреждение при запуске сервера в оффлайн-режиме (`online-mode: false` в `server.properties`).

## Устаревшие флаги

### -DLeaf.native-transport-type

(Присутствовал в Leaf 1.21.8)

- по умолчанию: `epoll`

Указывает модель сетевого ввода-вывода для передачи данных. Требует включения `use-native-transport` в `server.properties`.

Если указанный тип транспорта недоступен, произойдёт откат на поддерживаемый вариант.

Доступные значения:

- Linux: `io_uring`, `epoll`, `nio`
- MacOS: `kqueue`, `nio`
- Windows: недоступно

### -DLeaf.nearestEntitySensorBucketCount

(Присутствовал в Leaf 1.21.1 и 1.21.3)

- по умолчанию: `10`

Количество корзин (buckets) для блочной сортировки ([Bucket Sort](https://en.wikipedia.org/wiki/Bucket_sort)) при достижении порога числа сущностей.

Обычно рекомендуется корень из общего числа сущностей.

### -DLeaf.nearestEntitySensorBucketSortThresholdRatio

(Присутствовал в Leaf 1.21.1 и 1.21.3)

- по умолчанию: `2.0`

Коэффициент порога включения Bucket Sort `(Threshold = bucketCount * ratio)`.
